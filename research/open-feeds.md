# Free real-time public AIS sources worldwide

Compiled 2026-08-20. "[verified live]" = probed directly that day.

## Headline

Three public bodies publish a free, live, per-vessel AIS feed that we are licensed to re-serve: Norway (Kystverket + BarentsWatch), Finland (Fintraffic Digitraffic), and EuRIS (EU inland-waterway portal; bbox track endpoint is open, unauthenticated, near-real-time, 13 countries, but GDPR-anonymised). Everything else is historical, aggregated, reciprocity-gated, non-commercial, or government-only.

## Best candidates for re-serving

1. Finland Digitraffic MQTT: CC BY 4.0, no registration, push-based, verified 43 msg/s. Set `Digitraffic-User`.
2. Norway Kystverket TCP: one socket, no auth, tagged AIVDM, NLOD. Verified ~38 msg/s. Same message arrives from several base stations → dedupe on payload, not arrival. BarentsWatch adds JSON + EEZ/Svalbard on the same data.
3. EuRIS inland Europe: the survey's new find, absent from prior inventories including [`clemensv/real-time-sources`](https://github.com/clemensv/real-time-sources/tree/main/tools/candidates/maritime-ais). Positions ~3–6 min old, anonymised (stable `trackId`, no MMSI/name). Useful for "traffic near me", useless for "identify that ship". Check one bbox over a target area before wiring it.
4. Denmark daily S3 archive: backfill, density layers, decoder validation. ~636 MB/day.

## Redistribution split

Open, redistribution OK: Digitraffic (CC BY 4.0), Kystverket + BarentsWatch (NLOD), EuRIS (attribution string), Ulsan Port, UK MMO (OGL), Barcelona (CC BY-SA), MarineCadastre (public domain), EMODnet density, HELCOM density (CC-BY).

Free but forbidden/conditioned: USCG NAIS (no-retransmit, no-fee), aprs.fi (free-app-only, no caching), Global Fishing Watch (CC BY-NC), Kystverket restricted tier, AISHub (reciprocity: must feed a receiver; redistribution and commercial use confirmed OK by AISHub 2026-08-22), Rijkswaterstaat (agreement), HELCOM raw (multilateral agreement).

## Dead ends (one line each)

Denmark live feed dead; Sweden paid; Estonia only density grid + Nutimeri viewer without API; Latvia `ais.lgs.lv` is aeronautical; Lithuania port-call records only; Poland PHICS internal, not in EuRIS; Iceland nothing; Germany BSH 2017 density only, WSV no endpoint; Netherlands RWS gated; Belgium MDK/Antwerp internal; France 2021 static only; UK MCA/UKHO/PLA no feed; Ireland `erddap.marine.ie ais_met_hydro` is buoy telemetry over AIS, not vessels; ERDDAP AIS datasets are single research-ship telemetry; Spain/Portugal/Italy/Greece/Croatia/Slovenia/Malta/Cyprus/Romania/Bulgaria/Turkey VTS internal; NOAA CO-OPS/PORTS/nowCOAST no AIS; Great Lakes Seaway 403/login; Canada CCG/TC/MEOPAR/MERIDIAN no API; Australia historic sanitised only; New Zealand nothing; Japan JCG `msil.go.jp` unresolved; South Korea national = historical files + hourly aggregate, only Ulsan live; China/Taiwan/Singapore/Hong Kong nothing AIS-shaped; India/Malaysia/Thailand/Vietnam/UAE network-blocked, untested; Indonesia/Philippines/Nigeria regulatory portals; Panama Canal water levels only; Chile/Argentina CKAN count 0; Brazil/Mexico 401/403 inconclusive; South Africa/Egypt nothing; FFA VMS is government fisheries; Spire/exactEarth no academic tier; ShipXplorer SPA blocked; "OpenSky for ships" does not exist, nearest is aiscatcher.org community hub which is contribution-gated.

## Academic and institutional routes

UN Global Platform (exactEarth/FleetMon satellite + terrestrial, global since Oct 2018): a Spark/Jupyter compute enclave for the official-statistics community, contract "for statistical purposes", no external API, CSV aggregates only ([AIS Handbook](https://unstats.un.org/wiki/display/AIS/AIS+data+at+the+UN+Global+Platform)). Dead end for live serving. Commercial academic routes (Spire via Stanford/Redivis, Kpler research partnerships, GFW's ORBCOMM sublicense) all share one shape: analysis in a controlled environment, derived outputs only, no public display, no redistribution. The [ORBCOMM sublicense to GFW](https://globalfishingwatch.org/orbcomm-ais-data-sublicense-agreement/) grants only non-commercial visualization plus a news-media carve-out. Danish bulk archive: ~3-day lag, back to 2006, no explicit license file; DMA policy says live access is a paid annual subscription; confirm re-use rights with `sifa@brs2.dk`.
